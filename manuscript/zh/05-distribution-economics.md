# 第五册　发行、盈利与实验

**《AI短剧工程》试编教材 v0.1｜2026-10-13**

本册训练把作品、合同、费用和观众行为接在一起的能力。结业交付是一份渠道选择表、一份不重复扣除的项目账、一张指标字典和一个预先写好的实验方案。任何示例金额、比例、样本量均是假设，不是平台报价、历史实绩或赚钱保证。本册采用原创《退回重做》案例，尚无发行或真实收益。

## 第一章　先弄清楚谁向谁付钱

制作方的收入不一定来自观众。常见路径包括按合同委托制作、版权授权、平台收入分账，以及自己承担流量成本的经营。作品相同，合作方式不同，承担的风险也不同。委托更重交付、修改范围和验收；分账更重归因与结算口径；自购流量还要承担价格波动、转化与回收周期。

| 路径 | 收入依据 | 制作方首先要明确的内容 |
|---|---|---|
| 委托制作 | 里程碑或最终验收款 | 交付规格、修改轮次、验收时限、付款条件 |
| 版权授权 | 授权费或最低保证与分成 | 地区、期限、语言、媒介、独占、衍生版本 |
| 平台分账 | 合同约定的有效使用或收入基数 | 有效口径、扣减顺序、对账、结算时点 |
| 买量经营 | 用户与广告收入减获客成本 | 可追踪订单/用户、归因窗、回收周期 |
| 品牌定制 | 客户订单与传播交付 | 植入要求、修改责任、品牌验收与使用权 |

公开合作入口常只写依约收益。它证明有合作机制，不证明我们的账号、作品或AI形式一定有资格。FOX与HOLYWATER公告也说明品牌和IP合作是一种经营路径，并不代表新人拿到订单。[CM01：短剧创作者中心](https://www.shortdramas.com/)、[GM08：FOX公告](https://www.foxflash.com/releases/view/fox-entertainment-deepens-creative-content-portfolio-and-audience-reach-with-strategic-investment-in-vertical-video-technology-platform-holywater)

**具体例。** 若《退回重做》有人出资用于培训，要先确认他买的是一部成片、可修改源文件，还是长期独占权。三者对今后发行价值影响不同，不能只看总价相同。

**反例。** 平台说最高奖励几十万元，制作方把它记为已确定收入，开始全额制作。奖励通常有条件、期间与资格；广告金也不等于现金。

**练习。** 客户要求“无限修改直到满意”，固定价格看似覆盖全部生成费用，能否直接认定盈利？

**答案要点。** 不能。劳动与返工范围未封顶；还要确定谁能批准、哪些修改算变更、每轮反馈如何合并，以及付款是否与明确标准关联。

## 第二章　成本按合格交付计，不按生成按钮计

一次模型调用的价格只是费用的一部分。需要记录剧本开发、资产、试错、生成、剪辑、声音、字幕、本地化、质检、返修、授权与发布。一个漂亮片段若无法与前后镜头连接，它的费用仍然发生，但尚未变成合格成片。

本项目建议分两本账：现金支出账用于判断资金能否撑到结款；完整成本账加入自己的工时及共享设备分摊，用于判断长期是否值得持续做。给自己计时不意味着必须当月给自己发同额工资。已含员工薪酬的固定支出，又把同一工时按工资加一次，会重复计费。

可用以下结构，前提是每项互斥且归属明确：

`完整制作成本 = 项目现金制作支出 + 未在前项包含的劳动成本 + 合理分摊的共享成本`

`项目总成本 = 完整制作成本 + 权利费用 + 发行费用 + 实际承担的获客费用`

若权利或发行费已列入制作现金支出，就从后项排除。订阅套餐按项目占用分摊，不把整月套餐全部压到每一个项目。系统报错退款与结果不满意需要重做也不同；是否退费看当次工具与入口规则。[TS08：Runway生成报错说明](https://help.runwayml.com/hc/en-us/articles/32880432736659-Why-am-I-receiving-errors-when-trying-to-generate)、[API失败类别](https://docs.dev.runwayml.com/errors/task-failures/)

**具体例，全部为假设。** 样片生成现金900元、音频字幕等300元；自己工作20小时，内部计价80元/小时；共享软件合理分摊200元。分摊后的现金制作成本为1400元，完整制作成本为3000元；实际新增付款还须看软件费何时支付。若最终验收180秒，完整成本为16.67元/合格秒。生成过900秒并不能把分母扩大到900秒。

**反例。** 宣称“120分钟三天做完”，却不计选题、资产、等待、修正和后期。受访制作人的不同周期与费用也不能跨项目硬比较。[CM09：制作人访谈](https://www.thepaper.cn/newsDetail_forward_33101093)

**练习。** 已付套餐200元，另付外包400元，制作12小时；外包已包含配音。内部工时50元/小时，全部套餐仅服务此片。完整成本是多少？

**答案要点。** 1200元；现金600元，工时600元。不能再次增加已包含的配音费。若套餐服务多个项目，先确定合理分摊方式。

## 第三章　从平台流水到自己可用的钱

先定义结算基数B，再定义比例α。“收入分成50%”没有基数和扣减规则便无法计算。B可能是扣退款后的充值归因、有效观看收入，或平台定义的另一项数据。商店流水、广告收入、制作方应收和银行已到账是不同层次。一个金额若已经扣过渠道费，不能再次扣同一笔。

**假设合同示例。** 某期归因流水10000元，退款1000元；约定渠道扣费为退款后金额的20%，余下为分账基数。因此B=7200元。制作方比例50%，分账应收R=3600元。若合同明确保底G=2000元可抵扣此分账，则同一累计期间应收合计为`max(G,R)=3600元`。已收到2000元，只剩1600元待付；不能写成5600元收入。若合同写明额外不可抵扣的制作费F，才另外加F。不同期间、不同权利或有上限的合同不能机械套此公式。

项目贡献可用`最终结算归属收入－项目总成本`估计经营结果，但它不替代正式会计利润；实际可动用现金还受付款期、税费和欠款影响。保证金、代收款与未满足条件的奖励不要当可自由使用收入。

| 指标 | 本项目必须写清的定义 |
|---|---|
| 曝光、有效播放 | 平台如何计数，是否去重，是否含付费推广 |
| 开头保持率 | 进入后仍在指定时点观看的人数/合格开始人数 |
| 单集完成率 | 达到预定结尾标准人数/合格开始人数 |
| 续集进入率 | 下一集开始人数/本集符合条件人数 |
| 付费转化 | 付费人数/被纳入同一队列的合格用户数 |
| 单用户净收入 | 同队列同窗口归属净收入/用户数 |
| ROAS | 规定窗口的归因收入/广告支出，注明毛额或净额 |
| 全成本回收 | 制作方归属收入/全部项目成本 |
| 合格秒成本 | 对应范围完整制作成本/验收成片秒数 |
| 返工率 | 重做工时/总工时，或重做任务/总任务；两者不可混用 |

**反例。** ROAS为1.2就宣布盈利。它可能只比较收入和广告费，完全没覆盖制作、退款与渠道费用。ReelShort/Moloco案例把IAP和IAA并入D7口径，也没有说这就是项目净利润。[GM02：官方客户案例](https://www.moloco.com/case-studies/reelshort)

**练习。** 按本章假设，公司收到3600元，完整项目成本4200元，现金成本2600元。结果怎样表述？

**答案要点。** 项目贡献为负600元；若3600元已全部到账且其他现金条件不变，现金余额增加1000元。两个结果不矛盾，说明部分劳动等成本尚未形成当期现金支出。

## 第四章　把“我们觉得更好”变成可检验比较

改完故事看起来更顺，只能说明内部评议产生了新版本。想知道版本改变是否导致观众行为改变，需要比较设计。随机A/B将符合条件的用户按预定规则随机分到版本；非随机观察则包括今天发A、明天发B，或两个账号各发一个。后者会混入时段、推荐系统、人群与账号差异。

本项目借鉴在线实验方法：先写可证伪假设、随机化单位、主指标、保护指标和停止规则，再收集结果。该方法来自软件实验背景，短剧应用是我们的转用。[FM04：Microsoft实验指南](https://www.microsoft.com/en-us/research/articles/patterns-of-trustworthy-experimentation-pre-experiment-stage/)

《退回重做》的首轮理解测试可以邀请少量符合目标条件的人，各自看一个冻结版本，然后独立回答“日期在哪里被改、谁知道、责任依据是什么”。这用于找明显缺陷，不足以估计市场点击率。正式A/B则需更大且合适样本，规模由基线、最小有意义差异和不确定性要求决定，不能统一指定“20个人就够”。

**具体方案。** 假设只比较“审批关系先说明”和“稍后揭示”两版，其他内容尽量一致。按人随机分组；主指标为预先定义的时间线理解正确率；保护指标包括喜欢程度、困惑和继续观看意愿。真实发行时另测实际续看，不能把回答“会看”当实际观看。

正式方案还需规定观察窗口和统计分析，避免看到一个有利结果就提前停止；如使用序贯方法，应在开始前指定。检查两组人数是否异常、日志丢失、同一人看了两版和版本执行错误。样本不足时报告区间与不确定，不强行选赢家。

**反例。** A获1000播放、B获3000播放便归因B更好；这可能只是B得到更多曝光。即便随机分配后B点击提高，若理解、投诉或付费后满意恶化，也不能只看点击上线。

**练习。** 两天各发一个版本，B完成率更高。你能说什么，下一步做什么？

**答案要点。** 可以说观察到相关差异，不能确认因果。先检查来源、曝光、用户与时间差异；条件允许再做随机比较，或将结果仅作为候选线索，不伪装成A/B实验。

## 第五章　发行是一套交付，不是点上传

发行需要作品文件、元数据、权利资料、平台申报、字幕音频、版本标识、观看引导和对账责任。先确认具体产品通道，再用该通道的当前规则编交付表。微信小程序、视频号、腾讯视频不是一个结算产品；PineDrama广告版位可用，也不等于个人可以直接上传作品分账。[GM09：PineDrama官方广告说明](https://ads-useast2a.tiktok.com/resources/help/article/about-pinedrama-for-performance-auction-in-tiktok-ads-manager?lang=en)

中国《微短剧发展管理办法》已于2026-09-01施行，具体类别涉及不同许可、批准或平台审核编号；第34条涉及AI制作的每集提示。另有生成合成内容标识规则。交付时应按作品类别及平台当期要求核对，不能把研究笔记当已完成申报。[CM16：广电总局原文](https://www.nrta.gov.cn/art/2026/7/31/art_1588_73827.html)、[CM17：标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)

YouTube当前变现政策区分同角色但有新剧情的系列与模板批量重复内容。AI不是自动失去变现资格，也不是自动豁免原创、版权或广告友好性规则。[GM10：YouTube政策](https://support.google.com/youtube/answer/1311392?hl=en)

**具体例。** 《退回重做》发布包应能对应到同一版剧本、人物与道具记录、成片、字幕、音乐/声音许可和封面简介。更换剪辑后，要检查字幕时间与简介承诺是否仍正确。既有技能维护日志中也记录过素材重出后字幕失效的修正，说明这是实际流程依赖。[TS22：Drama Skills变更日志](https://github.com/zenstory-ai/drama-skills/blob/main/CHANGELOG.md)

**反例。** 为吸引点击，把故事包装成真实企业丑闻，正片却是虚构教学案例；或者引流说“完整结局”，实际只交三集样片。这会制造观看预期落差，不能以短期点击掩盖。

**练习。** 将同一中文片送到海外平台，除了翻译台词还应检查什么？

**答案要点。** 审批业务是否能被当地观众理解，字幕节奏与单位日期格式，声音和音乐权利地域，平台显示区域与规格，作品标识和合同范围。未经测试的直译不等于本地化完成。

## 第六章　让结果指导下一轮，不让好看的数字接管决定

看完数据后先检查数据是否能回答原问题。观看尖峰可能因为喜欢，也可能因为看不懂而重看；官方分析说明明确提醒这种多重解释。[FM03：YouTube留存指标](https://support.google.com/youtube/answer/9314415?hl=en)。评论说“不合理”也要定位到具体因果、人物动机或画面理解，不能直接整片推翻。

建议为每轮保存一张学习记录：冻结版本、假设、实际执行、费用与工时、指标结果、不确定性、负面信号、决定和下一版变化。决定分为继续、修复、暂停投入三种。暂未证明有效的版本可以继续做小试，但不能在没有证据时扩大预算。

**具体例。** 假设《退回重做》的观众理解显著改善，喜欢程度不明，单位合格成本却增加一倍。可先保留更清楚的因果结构，寻找更便宜的信息呈现方式；不必在“全保留昂贵版”和“完全回退”间二选一。若改完仍没人理解责任转移，应重新检查核心故事任务，而不是继续添加特效。

经济判断要做敏感性分析：结算单价、有效观看、工时或退款变化时，项目何时失去可行性。假设总成本1万元，制作方每一万结算单位收到10元，则需1000万个同口径结算单位回收；这不是1000万公开播放的盈利保证。若合同按观看时长结算，必须替换整个单位，而非沿用播放公式。

**反例。** 从最火十部剧提取共同标签，却不看同标签失败作品；这种幸存者偏差会把普遍套路误认成成功原因。也不能让AI自己写剧本、自己打分，再把高分称作市场验证。

**练习。** 当前版本达到点击目标，但投诉主要集中于“结尾没说清”“付费后发现不是完整作品”。是否立即加大推广？写出下一步。

**答案要点。** 先停止放大该缺陷，检查广告承诺与交付范围，修复结局或标明连载状态，并重新观察满意、退款和实际续看。既有点击可以保留为一个指标，不能抵消尚未兑现的承诺。只有完成真实交付与外部检验，本册账表和实验程序才开始产生有效的项目知识。
