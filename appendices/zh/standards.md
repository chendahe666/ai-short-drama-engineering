# AI 短剧制作与验证规范草案 v0.1

[English](../en/standards.md)

状态：项目内部草案，供试用评议；不是国家、行业或团体标准，不代表平台认可。研究截止：2026-10-13。适用对象：使用 AI 参与编剧、素材生成、编辑或音频处理的短剧项目。条款默认用于本项目的设计、制作、试播和交付记录，发布地与平台另行登记。

“必须”仅用于确有适用依据的外部义务或团队明确采用的项目约定；“建议”允许说明理由后采用替代方案；“假设”必须保留未验证状态，不能以审美判断或模型自评分升级为规律。外部义务以发布时有效原文及适用范围为准。本草案所设检查方法，除明确引用的原文要求外，均是项目工程安排。

检查结果只用四种：通过、待修订、不适用、未检查。“不适用”必须有理由；缺少样片、授权材料或观众记录时应填“未检查”，不能填“通过”。同一条款在剧本阶段通过，不等于成片或发布阶段通过。

## 条款

### SD001　确定发布范围与审核路径
**类别：外部义务，适用范围须核对。**
- 输入：项目发布国家/地区、播出平台、形态、预算、题材和负责主体。
- 检查：按适用规则辨明许可、批准文件、平台审核编号或其他路径；核对材料与拟发布版本对应。
- 通过：负责人员有据确认路径，发布阶段具备对应完成记录；没有用旧平台编号替代新平台要求。
- 例外：纯内部教案尚未播出，可记录发布检查未进行；不得因此声称以后可直接上线。
- 证据：范围卡、审核材料版本、人工核对记录；[广电办法第17、33条](https://www.nrta.gov.cn/art/2026/7/31/art_1588_73827.html)。分类判定不能仅靠自动估算预算。

### SD002　国内 AI 微短剧每集提示标识
**类别：外部义务。**
- 输入：每集送播成片、AI 使用说明、适用平台要求。
- 检查：逐集查看提示标识是否处于明显位置，是否被裁切、遮盖或在转码后丢失。
- 通过：适用该要求的每集均有符合当前规则的提示，并保存检查对应文件。
- 例外：其他法域按当地要求另列条款；草稿未出片时记未检查。
- 证据：成片哈希、逐集人工查看记录；[广电办法第34条](https://www.nrta.gov.cn/art/2026/7/31/art_1588_73827.html)。工具检测有标识不等于证明足够明显。

### SD003　使用发布平台的 AI 声明功能
**类别：外部义务，按适用法规执行。**
- 输入：平台发布界面、导出文件、生成来源说明。
- 检查：主动声明 AI 生成合成内容并使用平台提供的标识功能；检查流程未恶意删除或隐藏规定标识。
- 通过：平台声明与实际素材情况相符，发布状态有人工核对记录。
- 例外：平台没有相应选项时先核实该平台路径并记录处理，不能把缺少按钮当作豁免。
- 证据：声明记录、平台规则版本；[标识办法第10条](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)。

### SD004　权利链可供负责人员核对
**类别：外部义务；材料清单为项目约定。**
- 输入：故事来源、文本、参考图、音乐、声音、字体、真人形象与工具条款记录。
- 检查：由负责人员核对权利主体、授权范围、期限、地域、平台、AI 用途及相关限制；不以“AI 生成”替代核实。
- 通过：拟使用材料有可解释的权利依据，重要歧义已获得有权确认者的确认；仅有来源链接不视为授权。
- 例外：内部未发布草稿可保留未解决项，但应限制后续使用范围；不得将草稿检查替代商业发布检查。
- 证据：权利登记表、合同或适用许可、人工核对记录；[广电办法第10条](https://www.nrta.gov.cn/art/2026/7/31/art_1588_73827.html)。模型不能验证签约人的实际授权能力。

### SD005　制作前冻结项目简报
**类别：项目约定。**
- 输入：受众、渠道、画幅、集数与长度范围、画风、语言、交付格式、预算边界和验收角色。
- 检查：各字段可执行，互相矛盾处已解决；更新注明受影响资产。
- 通过：存在有版本的简报，当前工作能追溯到该版；未知商务条件明确列出。
- 例外：探索试验可暂不固定最终规格，但必须写出本次试验规格。
- 证据：项目简报及变更记录。依据是本项目工程约定；[短剧创作者中心](https://www.shortdramas.com/)的“依约”收益不支持统一报价。

### SD006　关键剧情有因果链
**类别：项目约定。**
- 输入：故事梗概、场景表、人物目标与行动后果。
- 检查：人工逐项问“角色为什么现在这样做”“行动导致什么”“反转依赖的信息此前如何获得”。
- 通过：关键行动与转折有可指出的依据，无未处理的自相矛盾；合理巧合有明确用途和边界。
- 例外：故意留白允许，但必须区分悬念与作者尚未解决的逻辑缺口。
- 证据：因果表、问题清单与修订。该条不要求所有观众喜欢人物，也不允许用模型逻辑评分代替审读。

### SD007　证据、时间与角色知识分开记录
**类别：项目约定。**
- 输入：关键文件/信息、出现时间、角色知道它的时间与来源。
- 检查：把客观发生、文件声称、人物相信的内容分列；《退回重做》中尤其核对 v7/v8 与客户确认状态。
- 通过：每次责任判断能追到故事内已有信息，角色没有无理由提前知道后续真相。
- 例外：不可靠叙述可采用，但误导范围与最终澄清位置需登记。
- 证据：知识时间线、版本对照和人工审读记录。教学故事事实由案例版本定义，不是现实事件证据。

### SD008　用连续镜头组检查一致性
**类别：项目约定。**
- 输入：角色参考、场景与道具状态、连续镜头组。
- 检查：人工连续观看身份、衣物、持物、空间方向、动作接续；自动相似度只作定位线索。
- 通过：没有影响理解且无剧情理由的身份、道具或动作跳变；有意变化有说明。
- 例外：回忆、梦境、时间跳跃允许变化，需让观众有辨识线索。
- 证据：镜头组检查表、问题时间码；[具名制作人访谈](https://www.thepaper.cn/newsDetail_forward_33101093)支持问题存在，具体门槛由项目定义。

### SD009　选用素材可追溯到版本
**类别：项目约定。**
- 输入：镜头编号、资产来源、模型/工具版本、输入参考、输出文件与人工修改。
- 检查：成片所用素材是否可定位；废弃和选用记录是否区分；不记录无必要的密钥和个人敏感信息。
- 通过：抽查任一关键镜头可找到实际选用文件与修改过程；无法重现的外部工具状态如实标记。
- 例外：供应商不开放参数时记录供应商、交付版本及已知限制，不能声称完全可复现。
- 证据：资产清单、文件哈希、生成与剪辑记录。本条为工程约定，不要求公开私有素材。

### SD010　记录全部生产成本
**类别：项目约定。**
- 输入：工具/算力账单、人工工时、失败尝试、授权、编辑、音频和推广支出。
- 检查：核对总成本是否遗漏返工和不可用生成；共享费用分摊规则是否稳定。
- 通过：已发生、已承诺、估计支出分列；可计算可用成片分钟成本，未知项仍显示未知。
- 例外：自有人工无现金支付时同时列现金成本与约定工时成本，不把人工默认为零。
- 证据：成本台账及凭据；[黄楚杰访谈](https://www.thepaper.cn/newsDetail_forward_33101093)与[九州采访](https://www.thepaper.cn/newsDetail_forward_33955220)只支持成本口径需要区分，不能充当统一行情。

### SD011　按约定技术规格交付
**类别：项目约定。**
- 输入：项目交付规格、实际编码文件、封面、字幕/音轨需求。
- 检查：分辨率、画幅、帧率、时长、音频编码与缺帧/黑帧；在目标设备完整播放。
- 通过：符合本项目及平台明确的技术规格，没有未解释的技术异常。
- 例外：创作所需的静帧、黑场等须标注，避免自动误判；规格冲突先处理版本。
- 证据：媒体检测报告与人工播放记录。通过技术检查不代表叙事或市场效果通过。

### SD012　对白、声音与音乐分别验收
**类别：项目约定。**
- 输入：对白台词、音轨、混音文件及约定设备。
- 检查：在手机外放及项目指定条件试听关键台词、音画同步、爆音与音乐遮盖；必要时检查电平。
- 通过：关键台词可辨，情绪表现经过人工审听，无未处理的音频错误；符合已采用平台响度要求。
- 例外：有意含混或失真应有剧情目的且不遮蔽必须理解的信息。
- 证据：试听条件、问题时间码与修订记录；[创作者节目说明](https://www.xiaoyuzhoufm.com/episode/6963ab5ce235ea65bc4bb08d)为流程参考。情绪感染力不能由响度指标认定。

### SD013　字幕与画面信息在目标设备可读
**类别：项目约定。**
- 输入：字幕、关键文件画面、平台界面遮挡区域与目标手机。
- 检查：核对人名、版本、日期及台词；实际查看停留时间、遮挡、对比度和行长。
- 通过：负责审查者能在正常播放条件下读到剧情必要信息，错字与不必要遮挡已解决。
- 例外：无法完整阅读的道具背景可不逐字展示；涉及剧情证据的字段不能以背景例外放过。
- 证据：字幕校对与设备检查记录。不设所有片子通用的固定字号或三秒停留规律。

### SD014　剧情理解测试与艺术评价分开
**类别：项目约定，进入试播阶段后采用。**
- 输入：固定版本、未被告知答案的目标参与者、预先写好的理解题和判定依据。
- 检查：记录每位参与者实际回答、是否被提示和与创作者关系；将理解错误与“不喜欢”分开。
- 通过：测试程序遵守计划，结果和分母完整，关键理解缺口已报告；是否足以发布由项目另定。
- 例外：尚无参与者时记未检查，不允许用多次模型回答冒充观众样本。
- 证据：匿名化测试记录、问题与分析。此处程序通过不等于作品效果已被证明。

### SD015　社区反馈保留语境与抽样边界
**类别：项目约定。**
- 输入：可读评论/帖子、平台、日期、所评作品、采样方式。
- 检查：区分观众、创作者、工具客户与营销导流；记录删帖、登录限制及未读取部分。
- 通过：每条被用于结论的反馈可追溯；没有把转载数量、点赞或少数发言写成总体比例。
- 例外：匿名或身份不明的反馈可用于提出问题，但不作为已确认行业事实。
- 证据：评论编码表与引用；[知乎推广回答](https://www.zhihu.com/question/1990728643920561512/answer/2015570176066736949)是利益关系检查例。

### SD016　经营指标有明确分母与到账口径
**类别：项目约定。**
- 输入：播放、用户、观看时长、热度、付费、分账、退款与成本数据及合同。
- 检查：逐项写单位、期间、来源、去重方式；区分平台收入、创作者收入、到账和利润。
- 通过：计算能从明细复算，保证金/保底是否可抵扣已说明；现金与广告金分列，未重复计入收入。
- 例外：只有公开榜单时仅报告榜单数据，项目利润记未知。
- 证据：指标字典、合同版本与结算台账；[快手财报](https://ir.kuaishou.com/zh-hans/news-releases/news-release-details/kuaishoukejifabu2026niandierjidujizhongqiweijingshenhecaiwuyeji)的工具收入不能当作品收益。

### SD017　发布版本有独立阻断项检查
**类别：项目约定，承接适用外部义务。**
- 输入：拟发布文件、平台、权利表、审核/标识记录及未解决问题清单。
- 检查：逐项确认是否存在缺少必要权利、审核、标识或关键交付的阻断问题；总分不得抵消阻断项。
- 通过：负责人员明确记录可发布的具体版本和渠道，必要项无未解决阻断。
- 例外：可交付内部草稿但必须标注状态；“有进展”不等于“发布通过”。
- 证据：版本清单与人工发布审查。此条不自动执行发布，不推定任何商业或版权授权。

### SD018　规则更新经过可追溯评议
**类别：项目约定。**
- 输入：规则提案、支持材料、反例、适用范围与影响分析。
- 检查：记录接受、部分接受、拒绝和待验证意见及理由；核对外部依据是否失效。
- 通过：新版本保留变更、适用日期与旧项目迁移方式；未解决分歧对使用者可见。
- 例外：紧急纠正事实错误可先发布更正，后补评议记录；不得回写成“从未出错”。
- 证据：RFC、意见表、版本日志；[历史团标](https://www.tvoao.com/userfiles/files/%E3%80%8A%E5%BE%AE%E7%9F%AD%E5%89%A7%E5%88%9B%E4%BD%9C%E7%94%9F%E4%BA%A7%E5%8F%8A%E5%86%85%E5%AE%B9%E5%AE%A1%E6%A0%B8%E6%8A%80%E6%9C%AF%E8%A7%84%E8%8C%83%E3%80%8B.pdf)与[状态页](https://www.ndls.org.cn/standard/index?draftman=%E9%9F%A6%E7%8A%81)说明版本核查必要。

### SD019　先验证高风险场景再批量生成
**类别：条件性建议。**
- 输入：场景复杂度、角色数、运动、工具已知限制、预算。
- 检查：找出最可能导致返工的镜头组，先做有限小样并记录可用率及工时。
- 通过：采用此建议时有样片和停止/调整决定；不采用时说明已有成熟资产或其他依据。
- 例外：完全复用且规格未变的已验收素材可简化，但新剧情连贯性仍需检查。
- 证据：小样成本与失败清单；[具名访谈](https://www.thepaper.cn/newsDetail_forward_33101093)支持先验证的动机，效果仍需本项目记录。

### SD020　固定“钩子秒数”只能作为实验假设
**类别：待验证假设。**
- 输入：关于信息揭示位置的假设、两版材料、主要结果、样本与终止计划。
- 检查：尽可能只改变目标因素；控制封面、音量等差异，记录招募/分发偏差与理解结果。
- 通过：实验程序和结果报告完整；无论正负结果均保留。仅在测得范围内修订建议，不升级为普遍法则。
- 例外：无法控制平台推荐时明确是观察性比较，不写因果提升百分比。
- 证据：预先计划、版本、原始观看记录及分析。模型自评、团队投票、播放总量均不能单独证明情绪或续看因果。

## 本次教案的符合性状态

《退回重做》仅进入原创教学设计阶段。上述条款是待执行的审查安排，没有成片、没有外部观众测试、没有上线结算；因此本文件不签发通过证书。可以审读剧本与资料结构，不能替代 SD002、SD008、SD011–SD014 等需要真实成片或观看材料的检查。

此前候选小说《公司扣我年终奖，我不忍了》的改编授权仍未核实。其市场讨论不为该小说的商业制作授权，也不为本原创教案的任何参考素材自动提供权利。

## 如何评议这份草案

对每条提交一个具体反例，说明是目标错误、范围过大、检查不可执行、成本过高还是缺少证据。下一版优先修复会导致误判或错误发布的条款，再简化重复记录。采用单位数量、实际完成的检查、审查者分歧和缺陷变化分别报告；在没有真实采用记录前，只称草案，不称行业标准或已经验证的方法。
