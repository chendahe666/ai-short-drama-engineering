## 方法与案例

[学科蓝图](appendices/zh/overview.md) · [原创案例《退回重做》](appendices/zh/case.md) · [20条标准草案](appendices/zh/standards.md) · [70条来源与访问边界](research/README.md) · [项目内总控skill](skills/ai-short-drama-production/SKILL.md)

核心做法是记录“问题—证据—适用条件—行动—验收—修订”。官方义务、项目约定、经验建议与待验证假设分别管理。平台营收、创作者收入、项目贡献与净利润使用不同口径。AI自评不能代替观众理解或市场结果。

## 中英双语与章节管理

`manuscript/zh`是中文原稿，`manuscript/en`是对应英文译稿；`book`中的72个章节页面由同一生成器维护。每章有稳定ID，如`B02-C03`。修改原稿后，源文件哈希会使对应翻译状态变为待复核，避免静默发布过期译文。

[翻译状态](TRANSLATION-STATUS.md) · [编辑与构建指南](CONTRIBUTING.md) · [版本记录](CHANGELOG.md) · [路线图](ROADMAP.md) · [结构参考](PUBLISHING-REFERENCES.md)

英文采用AI辅助翻译，已进行结构、引用完整性检查及部分交叉审查，尚未经过专业人工翻译审校。研究原始笔记和机器可读来源保留其原语言，英文读者可通过`research/README.md`定位；未将这些笔记伪称为全部已译。
